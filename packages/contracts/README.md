# @j-messenger/contracts

메신저의 decimal ID·opaque cursor·HTTP DTO·이벤트·validation 계약이다. 버전 `0.2.0`을 정확히 고정한다. 다른 서비스는 로컬 registry에서 설치하며 sibling source나 tarball을 저장소에 복사하지 않는다.

게시 전 전체 build/check 후 j-groupware의 `scripts/registry-publish.mjs --package <이 패키지 경로>`를 사용한다. publishConfig도 `http://127.0.0.1:4873/`으로 고정했다. 게시한 버전은 바꾸거나 지우지 않고 새 버전으로 올린다.
